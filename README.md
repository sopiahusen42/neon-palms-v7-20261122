# NEON PALMS

An original open-world crime game in the sun-soaked coastal city of **Neon Palms**.
Built with three.js (vendored, minified) — no build step, no network: open
`game/index.html` in desktop Chrome.

Play as **Marisol Vega**, a getaway driver working the palm-lined boulevards of
Neon Palms: steal cars, outrun a rising wanted level, and run five story jobs.

Entered in the make.fun **Make GTA 6** bounty.

## Play

```
node serve.ts          # or any static server rooted at game/
```

## Hand in

```
node main.ts           # writes /output (or $MAKEFUN_OUTPUT_DIR)
```
